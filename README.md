# LabEng — 实验室仪器控制引擎

用「框图」设计实验系统、用「例程插件」扩展测试功能的图形化仪器控制软件。
面向实验室场景：连接 Keithley 源表、直流电源、单色仪、频谱仪、AWG、示波器等仪器，
通过拖拽节点、填写参数即可运行测试，无需写代码；需要新功能时写一个 `.py` 例程文件即可，
甚至可以交给 AI 生成（见 [AGENTS.md](AGENTS.md)）。

## 三分钟上手

```bash
pip install -r requirements.txt
python lab_engine_app.py
```

1. **「测试系统设计」Tab** → 点「🗂 新建项目」：选创建方式、命名、勾选仪器 → 自动搭好框图。
2. 微调节点参数（选中节点，右侧面板编辑），需要说明就「+ 文本」放个便签。
3. 点「💾 保存」→ 生成例程 `.py` 文件（框图和面板配置都存在这个文件里）。
4. **「运行」Tab** → 下拉框选例程 → 连接仪器（或勾选模拟仪器）→ 填参数 → 「▶ 开始例程」。
5. 右侧实时绘图 + 日志；数据 CSV 保存在 `data/`。

没有硬件也能玩：例程的仪器连接面板里选模拟模式（mock），数据是假的但流程是真的。

## 三个 Tab

| Tab | 作用 |
|-----|------|
| 运行 | 选例程、连仪器、填参数、运行、看实时曲线和日志 |
| 例程结构 | 只读查看当前例程的框图（含保存时的布局），可一键「在设计模式中编辑」 |
| 测试系统设计 | 框图编辑器：新建项目向导、拖节点、连线、配置面板、保存例程 |

## 扩展方式（都不需要改引擎代码）

| 想要什么 | 怎么做 |
|---------|--------|
| 新测试例程 | 往 `lab_engine/routines/` 丢一个定义了 `NAME`/`PARAMS`/`run` 的 `.py`，GUI 点「🔄 刷新」 |
| 新仪器 | 写一个驱动类并在 `lab_engine/instruments/__init__.py` 注册（指南见 [AGENTS.md](AGENTS.md)） |
| 让 AI 写例程 | 用 Kimi Code 等 AI 打开本仓库，按 [AGENTS.md](AGENTS.md) 的格式约定直接生成 |

## 目录结构

```
lab_engine/          引擎本体
  app.py             主窗口（三个 Tab）
  core/              注册表、框图数据模型、运行时上下文、参数持久化
  gui/               各面板（框图编辑器、例程面板、连接面板、绘图、日志）
  instruments/       引擎层仪器注册（驱动复用 ivlab/）
  routines/          ★ 例程插件目录（递归扫描，即插即用）
ivlab/               底层仪器驱动库（SCPI/TSP/GPIB/VISA 封装）
AGENTS.md            AI 协作指南（生成例程/添加仪器的完整约定）
docs/TUTORIAL.md     教材：代码架构与学习路径
docs/                各轮迭代的测试报告
data/                运行数据、参数、草稿（自动生成，勿提交）
build_exe.bat        打包 Windows exe（双击运行，无需 Python）
```

## 打包给不会 Python 的人

双击 `build_exe.bat`，把 `dist/` 整个文件夹发出去即可。exe 旁边的 `routines/` 里放例程文件，
`data/` 里存数据和参数。
