## 意外发现（测试中带出、计划外修复的）

| 发现 | 说明 | 处理 |
|-----|------|------|
| `_build_routine_view` 节点叠加 | 「基于模板新建」二次调用时旧节点不清空，越叠越多 | 方法内强制从空图开始 |
| 临时连线坐标换算 | 原代码 `*= zoom` 漏乘 DPI scale（125%/150% 缩放下偏移） | 统一走 `_to_screen()` |
| ttk 按钮 state 返回值 | `btn['state']` 返回 index 对象而非 str，直接 `== 'normal'` 恒为假 | 测试代码修正（`str(...)`），非产品 bug |

## 遗留事项

1. **GitHub 远程仓库未创建**：本机没有 `gh` CLI，无法替你建库。请在 https://github.com/new 新建 `Zengyi-Xu/LabEng`（不要初始化 README），然后运行仓库根目录的 `push_to_github.sh`。

3. 参数持久化目前以例程 NAME 为 key；若例程改名，旧参数不会跟随（视为新例程）。
4. 「例程结构」Tab 仍默认只读，仅通过「✎ 在设计模式中编辑」进入编辑（符合既定设计）。
