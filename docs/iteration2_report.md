## 过程中发现并修复的问题

| 问题 | 原因 | 修复 |
|------|------|------|
| 嵌入 JSON 后例程无法加载 | `json.dumps` 输出 `true/false`，Python exec 报 NameError | 改用 `repr()` 嵌入 Python 字面量 |
| `_add_prop_entry` 丢失 | 编辑面板代码时误删函数头 | 补回，回归测试覆盖 |
| 锁定状态可编程加节点 | `_add_node` 无 `_editable` 守卫 | 加守卫 + 状态提示 |
| 打开旧 .labsetup.json 后仍锁定 | `set_graph` 未置 `_has_project` | 已修正 |
